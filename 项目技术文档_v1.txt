核心贡献: 用 Scharr边缘检测 + FFT频谱卷积 双分支模块替换 RT-DETRv2 的 CSPRepLayer,

2. 论文各节内容
-------------------------------------------------------------------------------
Abstract:
  - RT-DETR的FPN颈仅依赖空间域卷积, 忽略频率域信息
  - FreqSpatial: Scharr + FFT 双分支 CSP drop-in 模块
  - +1.45 mAP (46.73%→48.18%), 72轮匹配官方120轮性能
  - Epoch 0 +3.4 mAP margin 支持频率先验结论
  - 开源, 架构无关, 可推广到其他FPN颈

Introduction:
  P1: DETR进展, RT-DETR的FPN颈只依赖空间卷积 → gap
  P2: 频率域特征优势, FSDETR(小目标), FD-RTDETR(+0.7 COCO) → underexplored
  P3: FreqSpatial 方案 (基于FSDETR的Scharr+FFT, CSP封装, COCO验证)
  P4: 实验结果预览 (+1.45 mAP, epoch-0 +3.4)
  贡献: (1)COCO大规模验证 (2)CSP drop-in设计 (3)效率/冷启动/消融/定性分析

Related Work (3小节):
  (1) Real-Time DETR: DETR→Deformable DETR→DINO→RT-DETR→RT-DETRv2
  (2) 频域特征学习: FcaNet, GFNet, FSDETR(小目标), FD-RTDETR(COCO +0.7)
      "adopts FSDETR's Scharr+FFT and repackages as CSP neck block"
  (3) FPN: FPN, PANet, BiFPN, CSPNet

Method (4小节):
  (1) Preliminaries: Hybrid Encoder (AIFI + FPN+PAN)
  (2) FreqSpatialBlock: CSP双路径公式, FreqSpatial瓶颈×3
  (3) FreqSpatial Module: Scharr分支 + FFT分支 + 1×1 fusion
  (4) Design Rationale: 互补信息, drop-in替换

Experiments (7小节):
  Setup: COCO 2017, PResNet18, AdamW, bs=16, 640×640, 72轮, RTX 3090 ×1
  Main Results: Table 1
  Cold-Start: Table 2 (epoch 0, ImageNet backbone only)
  Training Dynamics: Table 3 + Figure 2(a)
  Efficiency: Table 4 + Figure 2(b)
  Ablation: FCM vs FreqSpatial (FCM 72轮 "in progress")
  Qualitative: Figure 3 (2 samples)

Limitations (5条):
  1. 无参数匹配基线 (Wide Baseline训练中, 将解决)
  2. 单数据集单架构
  3. 单次训练无多种子统计
  4. 无组件消融 (Scharr-only, FFT-only)
  5. 定性分析仅2例

Conclusion:
  +1.45 mAP, 72轮达120轮性能, cold-start +3.4
  主要trade-off: 3.9× FLOPs, 1.7× latency
  未来: 高效频域算子, 跨架构验证, 自适应频带选择

语言风格注意事项:
  审稿预演后已做hedging: "indicates/suggests/accounts for" 替代
  "confirms/demonstrates/drives", 已scope "any FPN neck" 到实际测试范围

6. 源码关键点
-------------------------------------------------------------------------------
fusion_modules.py (src/nn/backbone/):
  FreqSpatial类:
    - ScharrConv: 固定卷积核, G_x/G_y, 无learnable参数, groups=channels
    - Spatial path: Scharr → Conv3×3 → +x → Conv3×3
    - Frequency path: rFFT2D(norm='ortho') → separate real/imag → concat
      → Conv3×3 → view_as_complex → irFFT2D → Conv3×3
    - Fusion: element-wise add + 1×1 Conv
    - 关键: AMP autocast disabled for FFT (cuFFT不支持half precision)
    - NPU fallback: device=='npu'时仅使用空间分支
  FreqSpatialBlock: CSP双路径, N=3×FreqSpatial
  FCMBlock: 同样CSP, N=3×FCM, 1:3通道split+空间/通道交叉注意力

hybrid_encoder.py (src/zoo/rtdetr/):
  _create_fusion_block(): 工厂, block_type决定FreqSpatialBlock/FCMBlock/CSPRepLayer
  CSPRepLayer: in→2×(1×1 Conv), path_a→RepVggBlock×N→add path_b→1×1 out
  HybridEncoder: input_proj→AIFI(Transformer on stride-32)→FPN(top-down)→PAN(bottom-up)

presnet.py (src/nn/backbone/):
  PResNet18: depth=18, variant='d'(3×3 stem), 输出channels=[128,256,512]
  ImageNet预训练权重: PaddlePaddle格式 (ResNet18_vd_pretrained_from_paddle.pth)
