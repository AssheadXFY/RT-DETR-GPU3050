一、项目目标
--------------------------------------------------------------------------------
在 RT-DETR (DETR-based 实时目标检测器) 基础上，将 FSDETR 和 FCM 项目的创新模块
融合进模型的 Feature Pyramid Network (FPN/PAN) Neck 中，提升检测精度。
最终产出可用于学术论文的实验数据。

基线: RT-DETRv2-S (PResNet-R18 主干), COCO 2017, 72 epoch
官方参考: mAP 48.1% (120 epoch)
本项目 Baseline: mAP 46.73%
本项目 FreqSpatial: mAP 48.18%

三、核心创新模块
--------------------------------------------------------------------------------

1. FCM (Feature Cross-layer Modulation) -- 来自 FCM-main
   - 通道按 1:3 分割
   - 少量通道做空间细化 (3×3 conv ×2 + 1×1 conv)
   - 大量通道做语义变换 (1×1 conv)
   - Spatial Attention 加权空间分支, Channel Attention 加权语义分支
   - 双向互关注融合 (x33 = spatial(y4)*y3 + channel(y3)*y4)

2. FreqSpatial -- 来自 FSDETR
   - 空间分支: Scharr边缘检测 → 两次空间卷积
   - 频率分支: rFFT → 实数/虚数分离 → 频域卷积 → irFFT
   - 双分支相加后经 1×1 融合
   - 注意: NPU 不支持复数 JIT, 已加自动 fallback; GPU 上 FFT 需禁用 autocast

3. SHAB (Spatial Hierarchical Attention Block) -- 来自 FSDETR/SHViT (CVPR 2024)
   - 单头自注意力 (SHSA): 部分通道做 attention, 其余直通
   - DWConv + SHSA + FFN, 每步有残差链接

4. Block Type 可插拔系统 (hybrid_encoder.py 新增)
   - fpn_block_type='csp'  → CSPRepLayer (默认, 基线)
   - fpn_block_type='fcm'  → FCMBlock
   - fpn_block_type='freq' → FreqSpatialBlock


四、训练配置说明
--------------------------------------------------------------------------------
关键配置文件: rtdetrv2_pytorch/configs/rtdetrv2/include/

   - 训练 Resize: [640, 640]

   - 验证 Resize: [640, 640]
   - train_dataloader.total_batch_size=16
   - val_dataloader.total_batch_size=16

2. optimizer.yml:
   - 优化器: AdamW, lr=0.0001, backbone lr=0.00001
   - lr_scheduler: MultiStepLR, milestones=[1000], gamma=0.1
     注意: milestones=[1000] 是为120epoch设计的, 72epoch时全程无lr衰减
   - warmup: LinearWarmup, 2000步
   - use_amp: True, use_ema: True

3. 模型配置:
   - PResNet18, hidden_dim=256
   - HybridEncoder: in_channels=[128,256,512], feat_strides=[8,16,32]
   - enc_act='gelu', expansion=0.5, depth_mult=1, act='silu'
   - RTDETRTransformerv2: num_layers=3, num_queries=300, num_denoising=100
   - criterion: RTDETRCriterionv2, losses=[vfl, boxes], use_focal_loss=True

十二、常见 Bug 与修复
--------------------------------------------------------------------------------
1. Windows torchrun 失败 → --rdzv_backend=c10d --rdzv_endpoint=localhost:0
2. OpenBLAS 内存爆 → OMP_NUM_THREADS=1 num_workers=0
3. GradScaler 注册名错误 → @register() class GradScaler
4. FCMBlock concat 通道不匹配 → CSP双路融合
5. _ConvBN 1x1 padding → 自动 padding=(kernel-1)//2
6. FPN 尺寸不对齐 → F.interpolate 用 size= 替代 scale_factor
7. cuFFT half精度 → autocast('cuda', enabled=False) 包裹
8. NPU 复数JIT → x.device.type=='npu' 时跳过频域
9. conda rtdetr 空的 → 用系统python
10. ModuleNotFoundError → pip install scipy faster-coco-eval
11. COCO路径错误 → 必须在 dataset/coco/ 非项目根
12. GitHub密码认证 → 用Personal Access Token
13. 数据盘满 → 清理旧checkpoint+重复数据
14. HTTP2 framing error → git -c http.version=HTTP/1.1 push
15. Token泄露 → 立即删除重新生成
